Itinerum

Itinerum es una aplicación web que permite crear y gestionar itinerarios personalizados en Málaga sobre un mapa interactivo, utilizando la API de Google Maps para mostrar puntos de interés de forma visual. Cada parada del recorrido se añade directamente en el mapa y se acompaña de tarjetas con imágenes, descripciones y detalles prácticos, para que planificar un viaje se sienta como construir una ruta visual y no como rellenar un formulario. Además, los usuarios pueden guardar y consultar sus itinerarios cuando quieran, revisando fotos y puntos marcados como si navegaran por su propio mapa de viajes.
